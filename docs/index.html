esp-infoscreen — Web-Flasher

Firmware direkt aus dem Browser auf das ESP32-8048S070 flashen. Kein Tool-Setup nötig.

⚠ Dieser Browser unterstützt Web Serial nicht. Bitte Chrome, Edge oder Opera am Desktop verwenden (Firefox, Safari, iPhone/iPad funktionieren nicht).

1 · Voll-Firmware

Die komplette Infoscreen-Firmware (aktuelle Release-Version). Danach startet das Gerät den Einrichtungs-Assistenten (WLAN-AP „installer").

2 · Diagnose / Inventur

Kleine Diagnose-Firmware: liest aus, was auf dem Board steckt — Chip, PSRAM/Flash, DHT22-Sensor (inkl. gefundenem GPIO) und best-effort die Touch-Variante. Verändert keine Einstellungen; danach einfach die Voll-Firmware drüberflashen.
